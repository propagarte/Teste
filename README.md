# Estúdio de Campanha

Um estúdio criativo que cabe em **um arquivo só**: `estudio-de-campanha.html`.
Abra com dois cliques no navegador. Não precisa instalar nada, nem de internet.

## O que ele faz

1. **Gerador de conceito** — escolha um segmento (moda, alimentos, tech, beleza)
   e um humor (ousado, nostálgico, minimalista) e receba codinome, tagline,
   público, tom de voz, chamada para ação e três ideias de post.
2. **Paleta viva** — uma arte generativa desenhada em código, que muda de
   receita conforme o humor. Nenhuma imagem pronta é usada.
3. **Trilha** — um clima sonoro criado na hora com Web Audio. Cada humor tem
   velocidade, timbre, escala e batida próprios.
4. **Modo game** — placar de briefings resolvidos, nível, confete e um mapa
   das 12 combinações possíveis, que vão acendendo conforme você explora.

## Onde mexer (procure com Ctrl+F)

| Marcador | O que muda |
|---|---|
| `[1] PALETAS` | as cores de cada humor |
| `[2] BANCO`   | as palavras que viram o briefing |
| `[3] TRILHAS` | os sons de cada humor |

## Atalhos

- `Espaço` — gera uma campanha nova
- `S` — liga e desliga a trilha
